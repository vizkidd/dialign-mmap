dialign-mmap

DIALIGN 2.2.1 (vizkidd/dialign-mmap), compiled to WebAssembly. Runs entirely in your browser -- nothing is uploaded anywhere. Single-threaded WASM build (no OpenMP); output matches the native build (see CHANGES.md). One alignment per page load -- reload the page before running another (a fresh module instance is loaded per run to avoid stale state between runs; this keeps each run correct rather than keeping one instance around for speed).

Common options

Threading/mmap flags are not applicable here (this build is single-threaded and always runs with the equivalent of -nommap -- both verified byte-identical to the native defaults by this project's test suite) -- -threads/-nommap/-tmpdir in the extra-options field are accepted but have no effect.

-- logs every step (args, file writes, the WASM module's own exports, virtual-filesystem contents after the run) to this page, the browser console, and the module's own stdout/stderr, so an error can be retraced without re-running anything. Off by default to keep normal output uncluttered.
